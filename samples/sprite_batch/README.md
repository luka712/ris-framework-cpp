# sprite_batch

Loads `assets/kodim23.png` with `ris::Texture::from_image_file` and draws it once with `ris::SpriteBatch`.
Port of the `sprite_batch` example of ris-framework-ts and RisFramework.Demo.

`assets/kodim23.png` is image 23 (parrots) from the Kodak Lossless True Color Image Suite, downloaded from
<http://r0k.us/graphics/kodak/> and resized from 768x512 to 512x341. Kodak released the suite for unrestricted use.
